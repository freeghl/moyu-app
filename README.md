# 🐟 摸鱼神器 (Moyu App)

> 伪装成 VS Code 的多站点浏览器

## 功能

- 🎭 **VS Code 伪装** — 外观完全模拟 VS Code
- 🌐 **多站点标签** — 同时打开多个网站，标签页切换
- ➕ **自定义站点** — 随意添加/删除网站
- ⌨️ **老板键** — `Alt+Q` 一键切换到假代码界面
- 🙈 **快速隐藏** — `Alt+H` 隐藏窗口，`Alt+S` 重新显示

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt+Q` | 老板键 - 切换假代码界面 |
| `Alt+W` | 快速最小化 |
| `Alt+H` | 完全隐藏窗口 |
| `Alt+S` | 重新显示窗口 |

## 安装运行

```bash
# 安装依赖
pnpm install

# 启动应用
pnpm start
```
